# Enterprise Developer ERP Prompt (.NET 8 MVC)

## Objective

Build a production-ready, enterprise-grade **Developer ERP** (Construction & Real Estate Management System) using modern software architecture, clean coding principles, and scalable design. The application must support both on-premise and cloud deployment and be suitable for large real estate development companies.
